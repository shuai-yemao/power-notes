# Power Notes 层级知识库目录设计

## 1. 目标

将当前“一级分类 + 笔记列表”的平面知识库升级为可持续扩展的层级目录。每个一级知识库支持二级、三级和必要时的四级分类；用户可以从任意分类进入目录，并看到该分类及其所有子分类下的笔记。

## 2. 范围

### In scope

- 为四个一级知识库建立统一的树形分类数据。
- 为每篇 Markdown 笔记绑定完整分类路径。
- 在知识库目录页显示可展开的分类树、层级缩进、笔记数量和当前筛选状态。
- 点击任意分类节点时，筛选该节点及其后代节点下的笔记。
- 保留现有一级分类 URL 兼容行为，并支持通过 URL 恢复分类筛选状态。
- 在笔记阅读页显示当前笔记的完整分类路径，并提供回到对应分类的入口。
- 在桌面端保持清晰的目录与内容关系，在小屏幕下将树形目录改为可滚动或折叠的单列区域。

### Out of scope

- 不新增后端、数据库、登录和在线编辑能力。
- 不自动扫描文件系统推导分类；分类由 `notes.js` 中的显式元数据维护。
- 不虚构新的 Markdown 笔记内容；现有 4 篇笔记只绑定到规划好的分类叶子节点。
- 不改变现有 Markdown 文件路径和文章正文。

## 4. 数据结构

`notes.js` 增加分类路径元数据，不复制分类名称到多个页面：

```js
{
  slug: 'freertos-task-design',
  category: 'embedded',
  categoryPath: ['embedded', 'realtime', 'freertos', 'task-design'],
  categoryLabels: ['嵌入式', '实时系统', 'FreeRTOS', '任务与调度']
}
```

分类树单独作为 `KNOWLEDGE_TREE` 数据源。每个节点至少包含 `id`、`label`、`children`；笔记数量由笔记元数据计算，不在多个页面手工维护。

## 5. 页面行为

### 知识库目录页

- 左侧显示一级知识库和嵌套分类树。
- 当前一级分类默认展开；包含当前筛选节点的祖先路径自动展开。
- 选择分支节点时，展示所有后代叶子节点下的笔记。
- 选择叶子节点时，只展示该叶子节点下的笔记。
- 节点显示笔记数量；数量为零的节点仍可点击，但显示空状态说明。
- 搜索同时匹配笔记标题、摘要、完整分类路径和 Markdown 正文。
- URL 使用稳定的分类节点 ID 保存状态，例如 `library.html?category=embedded&path=embedded/realtime/freertos`。
- 现有 `library.html?category=embedded` 等一级分类链接继续有效，默认显示该一级分类的全部后代内容。

### 笔记阅读页

- 当前笔记顶部或元信息区域显示完整分类路径。
- 左侧“其他笔记”目录按当前一级知识库组织，笔记项显示其短分类路径。
- 分类路径中的每一级均可回到对应筛选后的目录页。

### 首页

- 现有四个一级知识库卡片继续作为入口。
- “按主题浏览”链接改为指向具体的二级或三级节点，而不是全部指向一级分类。
- 首页不复制完整树，避免首页信息密度过高。

## 6. 组件与职责

- `notes.js`：笔记元数据和完整分类路径的单一来源。
- `taxonomy.js`：四个一级知识库的树形分类定义及树节点辅助函数。
- `directory.js`：URL 状态、目录树渲染、分类筛选、搜索和笔记列表渲染。
- `note.js`：当前笔记分类路径和阅读页侧栏渲染。
- `library.html` / `note.html`：只提供语义化容器，不内嵌分类业务数据。
- `styles.css`：树形缩进、展开状态、计数、焦点态和响应式布局。

## 7. 可访问性与响应式要求

- 分类节点使用真正的按钮或链接，不使用不可操作的纯文本。
- 展开/折叠按钮提供 `aria-expanded` 和明确的可见焦点状态。
- 目录树在 320px 宽度下不得产生横向滚动；长分类名允许换行。
- 桌面端目录树与笔记列表并列；小屏幕改为顶部目录区或可折叠区，正文优先展示。
- 深色模式沿用现有高对比度颜色，零数量和禁用视觉不依赖颜色单独表达。

## 8. 错误与降级

- 分类节点缺失时，目录页回退到对应一级知识库或“全部”。
- 笔记缺失分类路径时，显示在其一级分类的“未归档”分组，并在开发检查中报告。
- Markdown 正文加载失败时，现有错误提示继续保留；分类导航仍可用。
- 分类树数据加载失败时，目录页仍显示笔记列表和搜索功能，不阻塞阅读。

## 9. 验证标准

- 四个一级知识库都能看到至少二级分类；嵌入式和工具与方法至少展示三级/四级路径。
- 点击任意分支节点只显示其后代笔记，点击叶子节点只显示该叶子笔记。
- 一级分类旧链接、首页卡片、首页主题入口、笔记阅读页分类入口均能正确跳转。
- 搜索可以匹配完整分类路径和 Markdown 正文。
- 目录树与笔记列表在浅色、深色和小屏幕下均可读、可操作。
- `node --check`、`git diff --check` 和本地浏览器视觉检查通过。
